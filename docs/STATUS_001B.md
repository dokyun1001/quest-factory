## 4. 그래픽 크기 및 건설 격자 기준
- 건설 격자 1칸은 64px(Tiny Swords 원본 타일 크기)이다. Unity에서는 PPU 64, 1칸 = 1 유닛으로 잡는다.
- 배율은 정수만 사용한다.
  - Tiny Swords ×1
  - Automation ×2 (32 → 64)
  - RPG 아이콘: 월드에서 ×2(32px), UI에서 ×3(48px)
  - Kenney UI ×2
- 보간 처리는 쓰지 않는다(Unity: Filter Mode = Point, Compression = None). 이동 시 흔들림 방지를 위해 Pixel Perfect Camera를 사용한다.
- 기계 크기는 2×1칸(충돌 범위 = 설치 칸)이다.
- 캐릭터는 측면 스프라이트만 있으므로 좌우 반전으로 방향을 표현한다.
