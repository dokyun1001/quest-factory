# QUEST FACTORY 개발 보고서 001 (웹 체험판)

작성일: 2026-11-24 · 개발 담당 Claude Code

## 0. 개발 방식 결정 경위
| 지시 | 내용 | 처리 |
|---|---|---|
| 001-B | Unity 6 + C#, 웹은 Unity WebGL 빌드 | 착수 전 001-C 접수 |
| 001-C | 클라우드 개발, Unity 라이선스와 클라우드 빌드 가능 여부 먼저 확인 | 확인 결과 Unity 실행에 사용자 Unity 계정 로그인이 필요해 클라우드 단독 진행 불가 |
| 사용자 결정 | "Unity는 지금 하지 말되 추후 제작", "웹 기술로 빠른 체험판" | **Phaser 3(JavaScript)로 웹 체험판 제작** |

- 이 체험판은 001-B의 "HTML/JS로 재개발 금지" 지시에 대한 **사용자 승인 예외**다.
- 나중에 Unity로 옮길 때 게임 코드는 다시 작성해야 한다.
- 그대로 재사용할 수 있는 것:
  - 기획 데이터: `web/src/data/defs.js`
  - 그래픽 매핑: `web/src/art/manifest.js`
  - 가공 에셋과 격자 기준

## 2. 구현 기능
| 기능 | 상태 | 내용 |
|---|---|---|
| 직접 조작 모드 | 구현 | 길드마스터가 걸어 다니며 나무와 금광을 직접 채집한다. 건물·기계·물에 충돌하고, 컨베이어 위는 걸을 수 있다. |
| 관리자 모드 | 구현 | 자유 시점, 2단계 줌, 건설 메뉴, 설치 미리보기(가능 초록 / 불가 빨강, 출구 방향 화살표), 시설 정보 창. 그래픽은 직접 조작 모드와 같다. |
| 물리적 컨베이어 | 구현 | 아이템이 실제로 벨트 위를 이동한다. 한 칸에 1개, 앞이 막히면 정체. 코너 회전과 합류도 지원한다. |
| 공장 자동화 | 구현 | 제련소(금광석→금괴), 가공 시설(금괴 2→황금 검), 의뢰서 조립기, 경험치 생산기, 전리품 회수 시설. 각 기계는 가동/대기/정지 상태를 애니메이션과 상태 램프(초록/파랑/빨강)로 구분한다. |
| 작업자 | 구현 | 일꾼 4명이 금광 채굴과 벌목을 하고(전용 애니메이션), 자원을 들고 길드 창고까지 운반한다. |
| 퀘스트 제작 | 구현 | 황금 검 → 퀘스트 의뢰서 → 의뢰 게시판에 게시하면 의뢰 수가 늘어난다. |
| 모험가 파견 | 구현 | 대기 중인 모험가가 의뢰를 받아 토벌 지역으로 이동해 전투하고 귀환한다. 귀환 시 골드와 전리품을 얻는다. 자동/수동 파견을 전환할 수 있다. |
| 길드 성장 | 구현 | 경험치 결정 → 길드 레벨 상승 → 모험가 정원 증가(3→6명), 상위 등급 몬스터 해금 |
| 도감 연구 | 구현 | 토벌하면 도감에 등록된다. 연구 기록과 해당 몬스터 전리품으로 연구(3단계)하면 길드 전체 보너스(의뢰 보상, 기계 속도, 컨베이어 속도)가 붙는다. |
| 전리품 기반 시설 강화 | 구현 | 기계를 선택하고 전리품으로 ★1→★3 강화하면 생산 속도가 ×1.5, ×2가 된다. |
| 저장·불러오기 | 구현 | 브라우저 localStorage. 20초마다, 탭 전환 시, 저장 버튼으로 저장된다. 접속하면 자동으로 불러온다. |
| 브라우저 키 충돌 방지 | 구현 | Tab, Space, 방향키, 휠, 우클릭 메뉴의 브라우저 기본 동작을 막았다. |

### 원본 보호 방식
- 원본은 비공개 저장소 `quest-factory-assets`에만 있다.
- 빌드할 때 필요한 그림만 **게임 전용 아틀라스 1장(4096×4096, 약 520KB)**으로 다시 포장해 배포한다. 공개 저장소와 웹사이트에 원본 파일 묶음은 올라가지 않는다.

### 적용하지 못한 에셋과 이유
- Tiny Swords Lancer: 프레임 하나가 320px라 아틀라스 용량을 많이 차지한다. 대신 전사·궁수·수도승을 사용했다.
- 몬스터: Tiny Swords 무료판에 몬스터가 없다(Enemy Pack은 유료라 구매하지 않음). 다른 진영 색 유닛에 색조를 입혀 임시로 쓴다.
- Automation Tileset의 세로형 기계와 코너 벨트 전용 타일: 직선 벨트를 회전해 사용한다. 코너 칸에는 나가는 방향의 직선 벨트가 표시된다.

## 4. 그래픽 크기 및 건설 격자 기준
- 건설 격자 1칸 = 64px(Tiny Swords 타일 크기). 시설 충돌 범위는 설치 칸과 정확히 같다.
- 배율은 정수만 사용한다.
  - Tiny Swords ×1
  - Automation 타일·기계 ×2
  - RPG 아이콘: 월드 ×2, UI ×3
  - Kenney ×2
- 보간 없음(`pixelArt: true`). 줌은 100%와 50%만 허용한다.
- 기계 크기는 2×1칸, 의뢰 게시판은 2×2칸.
- 캐릭터는 측면 스프라이트만 있어 이동 방향에 따라 좌우 반전한다.

## 7. 알려진 버그 및 미구현 사항
- 일꾼과 모험가는 직선으로 이동해 건물을 통과한다. 길찾기는 아직 없다.
- 전투는 연출 없이 시간 경과로 판정한다. 공격 애니메이션과 체력 개념이 없다.
- 컨베이어 코너 전용 그림이 없다(직선 벨트로 대체).
- 개발 지시서 001 원문을 받지 못해 세부 규칙은 001-A/B/C에 나온 기능명만으로 설계했다. 원문을 받으면 맞춰 조정한다.
- 길드 창고 내용을 보는 별도 화면이 없다(상단 자원 패널만 있음).
- 모바일 터치 조작은 지원하지 않는다.
- 사운드가 없다.

## 8. 추후 자체 제작이 필요한 에셋
퀘스트 의뢰서 조립기, 경험치 생산기, 의뢰 게시판, 전리품 회수 시설, 자원 투입구, 자동 분류기, 모험가 학교, 마법 연구 시설, 특수 채굴기, 전설 등급 시설, 몬스터 3종 이상과 보스, 컨베이어 코너 타일, 창고 UI.
현재는 각각 다른 그림을 빌려 쓰고 있다(`manifest.js`에서 `temp: true`로 표시). `manifest.js`의 경로만 바꾸면 교체할 수 있다.
